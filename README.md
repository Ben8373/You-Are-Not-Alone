# You Are Not Alone - Mental Health Support Website

## Project Overview

MindCare is a one-page responsive web application designed to provide a supportive and non-judgemental space for individuals seeking to improve their mental health. The website offers information about various mental health services and encourages users to reach out for support.

## User Value

- **Accessible Information**: Clear, organized content about mental health services
- **Supportive Environment**: Non-judgemental messaging to reduce stigma
- **Easy Navigation**: Intuitive single-page design with smooth scrolling
- **Responsive Design**: Works seamlessly across all devices
- **Interactive Elements**: Contact form with immediate feedback

## Features

- **Hero Section**: Inspiring message with call-to-action
- **About Section**: Information about the organization's mission
- **Services Section**: Overview of available mental health support services
- **Contact Section**: Interactive contact form
- **Responsive Navigation**: Fixed navbar with smooth scrolling to sections

## Technologies Used

- HTML5 with semantic markup
- CSS3 with custom properties and responsive design
- Bootstrap 5 for layout and components
- JavaScript for interactivity (smooth scrolling and form handling)
